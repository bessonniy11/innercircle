# 🧬 Структура Проекта "Звонилка"

Этот документ описывает структуру директорий и ключевых файлов проекта "Звонилка".

---

## 📂 Корневая структура

```
.
├── 📁 backend/      # Исходный код серверной части (NestJS)
├── 📁 docs/        # Вся документация проекта
├── 📁 frontend/     # Исходный код мобильного и веб-приложения (Flutter)
├── .gitignore     # Файл для исключения файлов из Git
└── README.md      # Главный файл проекта, точка входа в документацию
```

---

## 🔧 `backend/` — Серверное приложение

Сервер написан на Node.js с использованием фреймворка NestJS (TypeScript).

```
backend/
└── 📁 src/
    ├── 📁 auth/               # Модуль аутентификации и авторизации
    │   ├── 📁 dto/             # DTO для данных аутентификации (login)
    │   ├── 📁 guards/          # Гварды для защиты эндпоинтов (JWT, WebSocket)
    │   ├── 📁 strategies/     # Стратегии Passport.js (JWT, Local)
    │   ├── auth.controller.ts # Контроллер для HTTP-запросов
    │   ├── auth.module.ts     # Модуль NestJS
    │   └── auth.service.ts    # Сервис с бизнес-логикой
    │
    ├── 📁 call/               # Модуль для WebRTC звонков
    │   ├── 📁 dto/             # DTO для сигналинга WebRTC
    │   ├── 📁 entities/       # Сущность для хранения информации о звонках
    │   ├── call.controller.ts # Контроллер для получения WebRTC конфигурации
    │   ├── call.gateway.ts    # WebSocket Gateway для сигналинга в реальном времени
    │   ├── call.module.ts     # Модуль NestJS
    │   └── call.service.ts    # Сервис для управления логикой звонков
    │
    ├── 📁 chat/               # Модуль для чатов и сообщений
    │   ├── 📁 dto/             # DTO для создания чатов, сообщений
    │   ├── 📁 entities/       # Сущности (Chat, Message, Participant)
    │   ├── chat.controller.ts # Контроллер для HTTP-операций с чатами
    │   ├── chat.gateway.ts    # WebSocket Gateway для сообщений в реальном времени
    │   ├── chat.module.ts     # Модуль NestJS
    │   └── chat.service.ts    # Сервис с бизнес-логикой чатов
    │
    ├── 📁 invitation-codes/   # Модуль управления пригласительными кодами
    │   ├── invitation-codes.controller.ts
    │   ├── invitation-codes.module.ts
    │   └── invitation-codes.service.ts
    │
    ├── 📁 users/              # Модуль управления пользователями
    │   ├── 📁 dto/             # DTO для создания и обновления пользователей
    │   ├── 📁 entities/       # Сущности (User, InvitationCode)
    │   ├── users.controller.ts # Контроллер для операций с пользователями (регистрация, профиль)
    │   ├── users.module.ts    # Модуль NestJS
    │   └── users.service.ts   # Сервис с бизнес-логикой
    │
    ├── app.module.ts          # Корневой модуль приложения
    └── main.ts                # Точка входа в приложение
```

## 📱 `frontend/` — Клиентское приложение

Клиент написан на Flutter (Dart), что позволяет собирать его для Android, iOS и Web из единой кодовой базы.

```
frontend/
└── 📁 lib/
    ├── 📁 core/                   # Общие для всего приложения компоненты и сервисы
    │   ├── 📁 api/                 # Клиент для взаимодействия с REST API
    │   ├── 📁 config/              # Конфигурация приложения (URL, таймауты)
    │   ├── 📁 socket/              # Клиенты для WebSocket (основной и для звонков)
    │   ├── 📁 theme/               # Тема приложения (цвета, стили)
    │   ├── 📁 utils/               # Утилиты и хелперы
    │   └── 📁 widgets/             # Общие виджеты (например, ResponsiveLayout)
    │
    ├── 📁 features/               # Функциональные модули ("фичи") приложения
    │   ├── 📁 auth/                # Модуль аутентификации (экраны входа, регистрации)
    │   ├── 📁 call/                # Модуль звонков (экраны входящего, активного звонка)
    │   ├── 📁 chat/                # Модуль чатов (список чатов, экран переписки)
    │   ├── 📁 user/                # Модуль пользователя (список пользователей)
    │   └── 📁 home/                # Основной экран-контейнер с навигацией
    │
    └── main.dart                  # Точка входа в приложение, инициализация сервисов
```

## 📚 `docs/` — Документация

Вся документация проекта централизована в этой директории.

```
docs/
├── 📁 architecture/         # Описание архитектурных решений
├── 📁 guides/               # Руководства для разработчиков
├── 📁 infrastructure/       # Инструкции по настройке инфраструктуры (SSL, STUN)
├── 📁 project_management/   # Файлы по управлению проектом (задачи, правила)
└── 📁 reference/            # Справочные материалы (API, стек технологий)
```
