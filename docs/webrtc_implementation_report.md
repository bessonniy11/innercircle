**Проблема:** WebRTC звонки инициируются, но аудио не передается между пользователями

---

## 🔍 **Диагностика проблемы**

### **Выявленная причина:**
Отсутствие STUN/TURN серверов для NAT traversal, что препятствует установке peer-to-peer соединений между устройствами в разных сетях.

### **Техническое объяснение:**
- **WebRTC** требует STUN/TURN серверы для обхода NAT
- **STUN сервер** помогает устройствам обнаружить их публичные IP адреса
- **ICE протокол** использует STUN для установки соединений
- Без STUN сервера ICE кандидаты не могут быть правильно обработаны

## 📋 **План настройки STUN сервера**

### **Шаги для выполнения на сервере:**

1. **Установка coturn:**
   ```bash
   sudo apt install -y coturn
   ```

2. **Конфигурация:**
   ```conf
   # /etc/turnserver.conf
   listening-port=3478
   listening-ip=0.0.0.0
   external-ip=5.8.76.33
   no-auth
   no-tls
   no-dtls
   verbose
   ```

3. **Файрвол:**
   ```bash
   sudo ufw allow 3478/udp
   ```

4. **Запуск:**
   ```bash
   sudo systemctl enable coturn
   sudo systemctl start coturn
   ```
