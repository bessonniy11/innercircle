## 🚨 **Возможные проблемы**

### **Проблема 1: STUN сервер не отвечает**

**Симптомы:**
- `curl stun://5.8.76.33:3478` не возвращает ответ
- ICE кандидаты не генерируются
- Аудио не работает

**Решение:**
1. Проверить статус coturn: `sudo systemctl status coturn`
2. Проверить файрвол: `sudo ufw status`
3. Проверить логи: `sudo tail -f /var/log/turnserver.log`

### **Проблема 2: Порт заблокирован**

**Симптомы:**
- `nc -u -v 5.8.76.33 3478` показывает "Connection refused"
- `nmap -p 3478 -sU 5.8.76.33` показывает порт закрыт

**Решение:**
1. Открыть порт в файрволе: `sudo ufw allow 3478/udp`
2. Проверить настройки провайдера (возможно, блокирует UDP)

### **Проблема 3: ICE соединение не устанавливается**

**Симптомы:**
- ICE кандидаты генерируются, но соединение не устанавливается
- В логах: "ICE соединение не удалось"

**Решение:**
1. Проверить STUN сервер: `stunclient 5.8.76.33 3478`
2. Проверить сетевые настройки сервера
3. Добавить fallback STUN серверы (уже добавлены)
